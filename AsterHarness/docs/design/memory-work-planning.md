# 通过记忆维护工作与计划

当前阶段通过 prompt 指导 Agent 使用已有记忆管理工作。未来可能增加独立计划机制；目前没有计划专用工具、结构化状态、自动归档或调度。运行时不解析任务树。

指令位于 `agent_harness/core/context_manager/agent_context.py` 的 `MEMORY_WORK_GUIDANCE`，随持久 Thread 的通用记忆规则加载。[完整英文与中文翻译](../reference/memory-work-guidance-bilingual.md)。

指导适用于长期职责、跨很长时间推进的目标，以及临时事项：

- `index.md` 保留简短总览，使用 Markdown 嵌套列表表达关系，细节链接到其他记忆文件；简单事项无需复杂模板。
- 写清状态、已验证进展、下一步或恢复条件，并标出当前重点。
- 长期职责与本轮工作分开；临时事项可以与长期工作并存，根据用户意图调整。
- 有实质变化才更新；中断或恢复后结合记忆与新证据继续。
- 完成或取消后收束，保留有用结论与证据再移出活跃总览；遗留事项继续可见。旧结果和周期日志也应整合，避免无意义增长。
- 记忆不授予权限、不执行任务、不产生唤醒；无事可推进时等待事件。

例如，资料维护助手可以同时记住持续维护职责、进行数周的整理目标和一项临时查询。总览要求使用嵌套列表；状态措辞、层级细度和文件划分可按工作需要调整，不要求每个节点有固定字段。

现有记忆工具、版本、compact 和事件逻辑不变；不改写用户的 `instructions.md` 或已有记忆，不重启正在使用的实例。
