宿主权限

拥有整台 Linux / WSL 的管理员权限，通过原有工具执行。开启期间路径沙箱不生效；关闭后恢复原配置。切换时正常暂停并恢复同一个 Thread。仅用户可授予，不自动传给下级，不含 Windows 管理员权限。

由 UAC 确认。开启期间路径沙箱不生效；关闭后恢复原配置。仅用户可授予。

关闭后，命令按宿主当前用户的权限运行，路径隔离不生效；不因此获得 root 权限。切换在当前执行步骤结束后应用，保留同一个 Thread 和 worker。旧命令会结束，常驻监听按新权限重新启动。

单独授权 GPU 设备，不随路径可读写权限开放。可由持有 GPU 授权的直属上级转授，不自动传给下级；更改在当前步骤结束后应用，旧受管命令会结束。关闭沙箱或以 root 运行时，设备按宿主权限使用，仍保留此设置。
Linux / WSL：允许 Unix socket 通信，并默认提供隔离的临时目录，支持 LibreOffice 等程序。显式路径限制仍优先；可以连接已暴露且宿主用户有权访问的服务接口，此类服务可能代为执行超出路径权限的操作。不授予 root。更改在步骤边界应用，可在自身授权范围内转授。

可管理宿主当前用户的全部服务，包括创建服务、启动停止和查看日志。可通过服务执行宿主代码，超出路径沙箱；不授予 root 或 Windows 管理员权限。仅用户可授予，不自动传给下级。新成员创建后可在编辑配置中开启。

路径权限按权限查看和编辑路径；添加、修改或删除后，点击下方保存配置才会应用。
创建后将获得独立工作区、Relay 账号、MCP 和 skills。路径规则与沙箱开关在当前步骤结束后生效；修改模型或身份时正常暂停并恢复同一个 Thread。
