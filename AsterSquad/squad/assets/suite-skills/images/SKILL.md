# 图片生成与编辑

发现工具 `image_generate`、`image_edit`。生成可附参考图；编辑须提供本地目标图路径，可附额外参考图。说明用途、主体、画风、构图和限制；编辑明确修改什么、保持什么。精确裁剪、缩放和现有 SVG 修改适合普通代码工具。

```python
image_generate(prompt="花园首页横向插画，温暖手绘风，无文字", output_dir="images")
image_edit(prompt="只把杯子改成蓝色，保留形状、构图和背景", image_path="images/mug.png")
```

返回新文件路径和真实图片内容，不覆盖原图。可用 view_image 检查结果，确认后再放入项目。输入路径必须在当前文件权限内；输出目录位于自己的 workspace。图片在独立服务与官方 Codex 中处理，登录凭据不交给成员。

每次调用会启动一次性 Codex 任务，使用其内置图片工具，不转付费 API，不自动重试或迭代。内容、风格、尺寸等要求由 Codex 解释，不能保证内部参数逐字透传或像素精确保持。transparent_background=true 会检查输出是否实际含透明区域；不满足返回错误，不自动重做。

失败或超时可能已经消耗订阅额度。遇到 busy 本次没有开始；其他失败先核对回执或联系管理员，避免重复出图。不把“没有返回结果”当成“没有消耗额度”。一次性的 Thread 不保存常规会话记录，服务仍保留私有任务日志和图片用于排错。
